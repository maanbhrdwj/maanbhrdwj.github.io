🐍 Python Basics

What is Python?

Python is a high-level, interpreted programming language used for programming, data analysis, automation, machine learning and data science.

Why Learn Python?

  • Easy to learn
  • Widely used in Data Science
  • Useful for Data Analysis
  • Large number of libraries

1. Python Variables

A variable is a name used to store a value in a program.

Example

student_name = "Alex"
age = 18
marks = 85.5

print(student_name)
print(age)
print(marks)

Output

Alex
18
85.5

2. Python Data Types

Data types describe the kind of value stored in a variable.

  • int: Whole numbers, e.g. 10
  • float: Decimal numbers, e.g. 85.5
  • str: Text, e.g. "Python"
  • bool: Boolean values: True or False

Example

x = 10
price = 99.5
language = "Python"
is_easy = True

print(type(x))
print(type(price))
print(type(language))
print(type(is_easy))

Output

<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
